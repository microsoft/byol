# BYOL: Bring Your Own Language Into LLMs
[Syed Waqas Zamir](https://scholar.google.ae/citations?hl=en&user=POoai-QAAAAJ), [Wassim Hamidouche](https://scholar.google.com/citations?user=ywBnUIAAAAAJ&hl=fr), [Boulbaba Ben Amor](https://scholar.google.com/citations?user=8kGJcCIAAAAJ&hl=en), [Luana Marotti](https://uy.linkedin.com/in/luana-marotti), [Inbal Becker-Reshef](https://scholar.google.com/citations?user=gPfbTcMAAAAJ&hl=en), and [Juan Lavista Ferres](https://www.microsoft.com/en-us/research/people/jlavista/?msockid=1c0dc5b942ad679e2592d3d54300663a)

[![paper](https://img.shields.io/badge/arXiv-Paper-<COLOR>.svg)](https://arxiv.org/abs/2601.10804)

<hr />

BYOL (Bring Your Own Language) is a scalable framework for extending LLMs to low‑ and extreme‑low‑resource languages based on each language’s digital footprint. It combines language resource classification with targeted training pathways, achieving up to 12% gains over multilingual baselines for Chichewa and Māori, and enabling high‑accuracy LLM access for Inuktitut via a translation‑mediated approach.
